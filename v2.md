# Sanity CSV Import Plugin - v2 Backlog

Features and improvements planned for future versions.

## v2 Features

### Portable Text Support
- Accept Markdown in CSV cells
- Convert Markdown to Portable Text blocks on import
- Support basic formatting: headings, bold, italic, links, lists

### Collection-Level Menu Items
- Add "Import CSV" action to document type list pane menu
- Add "Download Template" action to document type list pane menu
- Schema type automatically detected from context
- No need to select document type manually

### Export Failed Rows
- After import completes, offer CSV download of failed rows
- Includes original data + error messages
- Easy re-attempt workflow: fix errors, re-upload only failed rows

### Plugin Configuration Options
```ts
// sanity.config.ts
import { csvImportTool } from 'sanity-plugin-csv-import'

export default defineConfig({
  plugins: [
    csvImportTool({
      maxRows: 1000,              // Override default 500 limit
      allowedTypes: ['product', 'post'],  // Restrict to specific types
      defaultDuplicateHandling: 'update', // skip | update | fail
    })
  ]
})
```

### Custom Field Transformers
Allow users to provide custom transform functions for specific fields:

```ts
csvImportTool({
  transformers: {
    // Custom price formatting
    'product.price': (value) => parseFloat(value.replace('$', '')),
    
    // Custom date parsing
    'event.date': (value) => new Date(value).toISOString(),
    
    // Custom reference resolution
    'post.author': async (value, client) => {
      const author = await client.fetch(
        `*[_type == "author" && username == $value][0]._id`,
        { value }
      )
      return { _type: 'reference', _ref: author }
    }
  }
})
```

### Rollback on Cancel
- Track all created document IDs during import
- If user cancels, offer option to rollback (delete created documents)
- Show confirmation: "Delete 23 documents that were created?"

## v2 Improvements

### Enhanced Validation
- Real-time validation as user types in wizard
- Show field-level errors inline
- Suggest fixes for common mistakes

### Batch Size Configuration
- Allow users to configure batch size for large imports
- Default: 50 documents per batch
- Configurable via plugin options

### Import History
- Track previous imports in local storage
- Show: date, document type, row count, success/fail counts
- Option to view details of past imports

### Undo Last Import
- Store IDs of documents created in last import
- "Undo" button to delete all documents from last import
- Confirmation required

### CSV Validation Mode
- "Validate Only" button that checks CSV without importing
- Useful for pre-checking large files
- Shows full validation report

### Progress Persistence
- If browser closes during import, resume on reload
- Store progress in local storage
- Show: "Previous import was interrupted. Resume?"
